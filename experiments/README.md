# Experiments

These scripts are standalone learning demos from the early stages of the project. They are not imported by the application.

- `ollama_test.py`, `embeddings_test.py`, `cosine_similarity.py`, and `pgvector_test.py` cover Ollama, embeddings, similarity, and pgvector fundamentals.
- `llm_system_prompt.py` and `function_calling.py` cover prompting and function-calling concepts.
- `langchain_basics/` contains LangChain comparison and learning references.

The application uses LangChain for RAG and LangGraph for the agent. See `docs/rag-pipeline.md` and `docs/architecture.md` for the current implementation.
